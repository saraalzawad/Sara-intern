# Merge Conflict Reflection

## What caused the conflict?

The conflict happened because I edited the same file in both the `main` branch and another branch before merging them.

## How did you resolve it?

I resolved the conflict by keeping both changes, removing the conflict markers, and then committing and pushing the resolved file.

## What did you learn?

I learned that merge conflicts happen when the same part of a file is changed in different branches. I also learned how to resolve conflicts before completing a merge.
