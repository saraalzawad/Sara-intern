I usually use Safari on my Mac for everyday browsing. For this task, I used Google Chrome and installed some developer extensions to learn what they do.

## Extensions I Installed

### React Developer Tools

- Used to inspect React components.

### Redux DevTools

- Used to debug Redux applications.

### JSON Viewer Pro

- Makes JSON data easier to read.

### Lighthouse

- Checks website performance and accessibility.

## Which extensions did you install? Why?

I installed React Developer Tools, Redux DevTools, JSON Viewer Pro, and Lighthouse. I wanted to learn how developers use these tools to inspect websites, debug applications, and view JSON data more easily.

## What was the most useful thing you learned?

I learned that browser extensions can make development easier. They help inspect websites, debug problems, and improve website performance.
