# Static Analysis Checks in CI/CD

## What is the purpose of CI/CD?

CI/CD helps developers test and check their code automatically before it is merged. This helps find problems early and keeps the project working correctly.

## How does automating style checks improve project quality?

Automatic checks make sure the code follows the same style and can find simple mistakes before the code is merged. This makes the code easier to read and maintain.

## What are some challenges with enforcing checks in CI/CD?

Sometimes the checks can fail even for small mistakes, and it can take extra time to fix them. Setting up CI/CD can also be difficult at the beginning.

## How do CI/CD pipelines differ between small projects and large teams?

Small projects usually have simple checks, while large teams use more tests, code reviews, and automatic deployments because many people work on the same project.
