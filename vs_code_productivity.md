I already had VS Code installed because I use it for my university projects. However, I did not know many keyboard shortcuts before this task. I searched for useful VS Code shortcuts for Mac and learned some new ones that I think will help me work faster.

### Navigation

1. **⌘ + P** – Quickly open a file.

2. **⌘ + Shift + P** – Open the Command Palette.

3. **⌃ + G** – Go to a specific line.

### Editing

4. **⌘ + /** – Comment or uncomment a line.

5. **⌥ + Click** – Add multiple cursors.

6. **⌘ + D** – Select the next matching word.

7. **⌘ + Z** – Undo changes.

### Terminal

8. **⌃ + `** – Open or close the integrated terminal.

### Debugging

9. **F5** – Start debugging.

10. **Shift + F5** – Stop debugging.
