# Kanban Workflow

## Research & Learn
Q1:Kanban board is a visual tool that helps organise tasks. It shows what needs to be done, what is in progress, and what has been completed.
Q2: The columns show the stage of each task. For example, Backlog is future work, In Progress is work being done, Blocked is work waiting for a solution, and Done is completed work.
Q3:The person working on the task is responsible for updating its status.
Q4: Limiting work in progress helps people focus on fewer tasks, finish work faster, and reduce overload.

## Reflection
Q1:Kanban helps me organise my tasks and see which ones are the most important. It also helps me focus on one task at a time.
Q2:I can improve my workflow by updating my tasks regularly, focusing on completing one task before starting another one.
Q3:I can improve task tracking by breaking large tasks into smaller tasks and updating the Kanban board regularly.
