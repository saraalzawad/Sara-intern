# When to Use Google, AI Tools, or Ask for Help

## Troubleshooting Strategy

### Use Google
- To find documentation or error messages.
- To look for examples from other developers.

### Use AI Tools
- To understand code and get explanations.
- To generate simple examples or ideas.
- To help debug small problems.

### Ask a Colleague
- When I have tried different solutions but still cannot solve the problem.
- When the issue is related to the project or team decisions.
- When I need advice or feedback.

## Simple Decision Guide

Problem?
│
├── Need documentation or error explanation?
│   └── Use Google
│
├── Need help understanding code or debugging?
│   └── Use AI
│
└── Still stuck after trying?
    └── Ask a colleague

## Reflection

### When do you prefer using AI vs. searching Google?

I use AI when I need an explanation or example. I use Google when I need official documentation or to search for a specific error.

### How do you decide when to ask a colleague instead?

I ask a colleague after I have tried solving the problem myself and cannot find the answer.

### What challenges do developers face when troubleshooting alone?

It can take a lot of time, and sometimes it is hard to notice mistakes without another person's help.
