# AI Tools

## Which AI tools did you try?

I installed the GitHub Copilot extension in VS Code. I also already use ChatGPT and Claude to help me learn programming and solve coding problems.

## What did you use them for?

- GitHub Copilot: Code suggestions inside VS Code.
- ChatGPT: Explain coding concepts, Git commands, SQL, and Python.
- Claude: Explain programming topics and help understand code.

## What worked well? What didn't?

These tools help me understand code faster and save time when learning. However, I still need to check the answers and make sure I understand the code instead of just copying it.

## When do you think AI is most useful for coding?

I think AI is most useful for learning new concepts, debugging errors, writing simple code examples, and explaining code.
