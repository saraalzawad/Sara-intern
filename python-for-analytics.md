# Python for Analytics Reflection

Python is preferred for data analytics because it is easy to learn and has many useful libraries. Pandas helps load, organize, and analyze data. Matplotlib and Seaborn help create charts that make data easier to understand. In Focus Bear, data analytics can be used to track user activity, create reports, and understand user behavior.

## Python Libraries

- **Pandas** – Used to load and work with data.
- **NumPy** – Used for calculations with numbers.
- **Matplotlib** – Used to create basic charts.
- **Seaborn** – Used to create nicer and easier-to-read charts.

##Python Example

```python
import pandas as pd

data = {
    "Name": ["Sara", "Ali", "Noor"],
    "Hours": [5, 3, 7]
}

df = pd.DataFrame(data)

print(df)
```

This code creates a simple dataset and prints it.
